# Zekke Makarna – Yönetim Panelli Statik QR Menü

## GitHub'a yükleme

Bu klasördeki dosyaların tamamını mevcut `menu` deponuzun ana dizinine yükleyin.

Mevcut dosyalar sorulursa **Replace files / Dosyaları değiştir** işlemini onaylayın.

Dosyalar:

- index.html
- style.css
- script.js
- menu.json
- admin.html
- admin.css
- admin.js
- qr-kod-olustur.html

## Menü adresi

https://zekkemakarna.github.io/menu/

## Yönetim paneli adresi

https://zekkemakarna.github.io/menu/admin.html

## Panel nasıl kullanılır?

1. `admin.html` adresini açın.
2. Ürün ekleyin, silin veya fiyatını değiştirin.
3. **Güncel menu.json İndir** butonuna basın.
4. GitHub deposunda mevcut `menu.json` dosyasını açın.
5. Sağ üstteki çöp kutusuyla eski dosyayı silip commit edin.
6. **Add file > Upload files** ile indirdiğiniz yeni `menu.json` dosyasını yükleyin.
7. **Commit changes** butonuna basın.
8. Yaklaşık 1 dakika sonra menü güncellenir. QR kod aynı kalır.

## Önemli

Bu panel statiktir. GitHub dosyasını doğrudan değiştirmez; güvenli biçimde yeni bir `menu.json` üretir.
